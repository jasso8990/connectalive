# Connectalive

Clase o taller en vivo por video, con papeles claros:

- **Dirigente** — quien conduce. Ve todo, aprueba todo, decide destinatarios.
- **Alumno** — habla, ve, escribe, comparte pantalla (con permiso), manda
  archivos (con permiso). Interactúa.
- **Oyente** — ve y escucha. Puede levantar la mano; si el dirigente le da
  la palabra, habla; el dirigente se la quita cuando quiera.

Front en HTML/JS plano · Supabase (auth, estado, realtime) · LiveKit
(audio/video/pantalla) · Netlify (hosting + funciones serverless).

Detalles del proyecto en `CLAUDE.md`.
